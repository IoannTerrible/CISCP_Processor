      Operands: A, R0..R7, SP, FLAGS, imm8 (number, 'c' or label),
      [addr] direct, [Rn] register indirect, [addr+Rn] indexed.
      Directives: .org addr, .db v, "text", .ds count, .equ NAME, value.
      Numbers: 255, 0xFF, $FF, 0b11111111. Comments start with ;.
